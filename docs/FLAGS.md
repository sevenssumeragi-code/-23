# フラグ台帳

シナリオが立てるフラグの一覧。命名規則は `[対象]_[種別]_[連番]`。
値は基本 `1`、`MUN_CUT_XX` のみ整数カウンタ。

- フラグの読み書きの仕組みは `docs/ENGINE.md` §8 を参照
- エンディング判定に直接使われるものには **判定** 列に ○ を付けた
- 「参照」が `—` のものは、現時点では**立つだけで誰も読んでいない**。
  資料パネルの表示や、後続章での利用余地として残されている

`tools/check.mjs` の静的検査が「参照されるのに一度も立たないフラグ」を検出するので、
新しい条件を書くときはここと実装の両方を更新すること。

照合すると失踪者本人だと判明し、以降ゲルとの通話で

§10 涙2「言えなかったわりい」への布石。制限時間つきの選択で、
黙っていると押せないまま終わる。

## 9. 周回を跨ぐ状態

フラグは**周回ごとにリセットされる**。周回を跨ぐのは `G` に入るものだけ。

| 名前 | 内容 |
|---|---|
| `LOOP_02` | 周回開始時に現在の周回数が入る。`hide:{loop:2}` の隠し選択肢に対応 |
| `G.recs` | 裏を暴いた録音IDの配列（r01〜r07）。`recs:n` 条件で参照 |
| `G.endings` | 到達済みエンディング名の配列。`cleared:X` 条件で参照 |
| `G.stills` | 解放済みスチルID |
| `G.memo` / `G.evd` / `G.rel` / `G.tl` | 次周回へ引き継ぐ資料 |
