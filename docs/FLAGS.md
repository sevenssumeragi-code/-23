# フラグ台帳

シナリオが立てるフラグの一覧。命名規則は `[対象]_[種別]_[連番]`。
値は基本 `1`、`MUN_CUT_XX` のみ整数カウンタ。

- フラグの読み書きの仕組みは `docs/ENGINE.md` §8 を参照
- エンディング判定に直接使われるものには **判定** 列に ○ を付けた
- 「参照」が `—` のものは、現時点では**立つだけで誰も読んでいない**。
  資料パネルの表示や、後続章での利用余地として残されている

`tools/check.mjs` の静的検査が「参照されるのに一度も立たないフラグ」を検出するので、
新しい条件を書くときはここと実装の両方を更新すること。

### 序章で新設したフラグの使いどころ

序章は design §4 で「あえて疑問を最小にし油断させる」ことが要求されている唯一の章。
そのため加筆は不穏さではなく、日常の手ざわりと操作の学習に厚みを置いた。

`TUTO_*` は取り逃しても本筋・エンディング判定に一切影響しない。
手引きを読まなくても進行するが、読むと「一、こちらから電話を切らないこと」という
三行の心得が手に入る。この一行目は五章（十年前に破った相談員がいる）と
終章（切らないことだけで歴史が変わる）で意味が反転する。

`MRI_LOG_01` は伏線③の補強。設計の「名札が外されている」だけでは
五章の室井との接続が弱いため、前任者の筆跡と、十年前の8月14日で
途切れる日誌を置いた。**この時点では名前を出さない**（2周目のスチル18で
はじめて「室井」の名が見える）。

### 第三章で新設したフラグの使いどころ

`NEO_CROSS_01` は本文中でネオの声が割り込んだ時点で立ち、その場の選択肢

`HYU_DEFECT` は指摘ルート（`HYU_BLAME`）を通らなくても、

`HYU_SUBJECT` は第一章の `MUN_WHITE_ROOM` か第二章の `JIN_TAPE` を
持っていると開く照合で、失踪者の共通点が施設ではなく被験者であることに到達する。

## 8.5 追補で追加されたフラグ

`docs/design.md` の追補（疑念／メモ札／折り返し発信／留守電／通話時間／同時着信）で
追加されたもの。エンジンが自動で立てるものと、シナリオが立てるものがある。

### エンジンが立てる派生フラグ

| フラグ | 立つ条件 |
|---|---|
| `MB_<key>` / `MD_<key>` | メモに〈信じる〉／〈疑う〉の札を付けた。キーは rain / bro / sensei / limp / jin_regret / mri / place / seventh の8種 |
| `MDCOST_<key>` | 〈疑う〉の代償を一度支払った印。札の付け外しで累積させないためのもの |
| `VM_<key>` | その留守番電話を再生した |
| `VM_LOST_<key>` | 再生しないまま二晩を過ぎて上書きされた |
| `VM_MISS` | **カウンタ**。上書きで消えた留守電の累計。3件で全員のストレス+6・疑念+5、5件でムニの恐怖+12・ノイズ+1 |
| `MULTI_MISS` | **カウンタ**。同時着信で迷っているうちに両方取り逃した回数 |
| `OVERTIME` | **カウンタ**。04:00 を越えて通話を続けた夜の数。1段ごとに選択肢の制限時間が12%短縮（最大4段） |
| `KAI_ALERT` | 澪原中央病院へ折り返して灰堂本人と話した＝こちらの存在を知られた |
| `MUN_DIAL_01` / `MRI_DIAL_01` / `CAN_ANSWER` | 折り返し発信が繋がった記録 |

## 9. 周回を跨ぐ状態

| `G.stills` | 解放済みスチルID |
