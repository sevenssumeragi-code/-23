# 1. 世界観・舞台

- **舞台**: 地方都市・澪原市(みおはらし)。山あいの霧が濃い街。市営の夜間電話相談窓口「みおはらライン」が舞台。
- **主人公**: プレイヤー=夜間相談員(名前入力可/デフォルト「灯(あかり)」性別不問)。相談ブースから一歩も出られない。武器は「声・耳・記録・電話機」のみ。
- **勤務時間**: 毎晩22:00〜翌4:00。ゲームは全14日間(Day1〜Day14)。
- **背景設定**: 十年前の8月14日、児童養護施設「灯守園(ひもりえん)」火災事件。園児1名死亡、職員1名が放火犯として服役(獄中死)。今年はその十周年。そして二週間前から市内で若者の失踪が続いている。
- **超常設定(終盤開示)**: 澪原市は現実と異空間〈渡岸(とがん)〉の境界が薄い土地。境界の裂け目は「音」に反応し、特に電話回線を伝う。だからこの相談室の電話は、時々「今ではない時間」「ここではない場所」に繋がる。

# 2. ゲームシステム設計書

## 2-1. 電話システム(コア)

| 機能 | 仕様 | ゲーム的意味 |
|---|---|---|
| 相談受付 | 着信ランプ点灯→「受ける/見送る」選択。同時着信あり(最大3回線) | どの声を優先するかが分岐。見送った電話は留守電へ |
| 通話時間 | 1コール上限のリアルタイム制(章により5〜20分相当のAP制)。長話しすると他の着信を逃す | 時間資源の管理=難易度 |
| 切電 | プレイヤー側切電/相手側切電/回線断(ノイズ切断)の3種 | 相手側の「不自然な切れ方」が伏線。プレイヤーの切電は信頼度低下 |
| 保留 | 通話を保留し別回線へ。保留中も相手の精神状態は変動(不安上昇) | 2回線同時事件の緊張演出 |
| 折り返し電話 | 履歴から発信。相手が出るかは時間帯・信頼度・生死フラグ依存 | 「もう二度と繋がらない番号」の演出に使用 |
| 発信 | 入手した番号にのみ発信可。存在しない番号=話中音、死者の番号=無音の後に… | 謎解きの能動アクション |
| 留守番電話 | 見送り/不在時にメッセージが残る。一部は雑音のみ | 聞き逃し防止と恐怖演出(深夜に増える無言メッセージ) |
| 録音再生 | 全通話を自動録音。波形表示付きで再生・逆再生・0.5倍速可 | 減速再生で「背後の声」「二重音声」を発見=証拠化 |
| 通話履歴 | 日時/相手/通話時間/切電理由を一覧化 | 「通話時間0秒の着信」「存在しない局番090-XXXX-1994」が考察対象 |

## 2-2. 情報管理システム

- **相談メモ**: 通話中に重要語が自動ハイライト→メモ帳へ。プレイヤーが任意でマーカー(信じる/疑う)を付けられ、これがフラグになる。
- **人物相関図**: 判明した関係が線で結ばれていく。周回するとTRUE用の「隠し線」(点線)が浮かぶ。
- **事件年表**: 判明した出来事が自動登録。**十年前の欄が最初から空白1行分確保されている**(=ムニの死。周回考察の火種)。
- **証拠一覧**: 録音断片/メモ/新聞記事/留守電がカード化。矛盾する証拠を重ねると「照合」演出。
- **相談者プロフィール**: 声紋アイコン・判明情報のみ表示。嘘が暴かれると項目に赤線訂正が入る。

## 2-3. パラメータ(相談者ごと)

| パラメータ | 範囲 | 上下要因 | 効果 |
|---|---|---|---|
| 信頼度 | 0〜100 | 傾聴・約束の遵守・秘密の保持 | 一定値で本音イベント/秘密開示 |
| 疑念 | 0〜100 | 矛盾の指摘の仕方・詮索 | 高いと重要情報を隠す/偽情報を流す |

| 精神状態 | 安定/動揺/混乱/危機 | 上記の複合 | 声の演技・BGM・選択肢の残り時間が変化 |
| 生死 | 生存/危篤/死亡/消失 | フラグ依存 | 「消失」は死亡と別枠(異空間持ち去り)。折り返しの結果で判別 |

# 4. 章構成・シナリオ設計

構成: 序章+全6章+終章。各章=ひぐらし式の「編」。

## 序章「もしもし、きこえますか」(Day1)
- **事件**: なし。チュートリアル。レニィの「授業中寝すぎて怒られた」相談で操作を学ぶ。
- **張る伏線**: ①レニィの通話の背後に雨音(その夜、澪原は晴れ) ②レニィ「最近、夢で誰かが僕を呼ぶんだよぉ」 ③壁の掲示「前任相談員 室井」の名札が外されている
- **終了時の疑問**: この平和はいつまで続く?(あえて疑問を最小にし油断させる)

## 第一章「うたたね編」(Day2〜4) 平和→違和感
- **事件**: 3:33、存在しない局番から着信。5歳の**ムニ**「おにいちゃんに会いたい」。切っても履歴に残らない。
- **張る伏線**: ①ムニの背後で流れる歌はレニィの鼻歌と同じ曲 ②ムニ「おそとがずっと夏だよ」 ③レニィの異常な眠気(夢でムニに会っている) ④留守電に無言メッセージ増加
- **回収する伏線**: 序章の雨音→レニィの家は施設跡地の近く=局地的な「境界の雨」
- **終了時の疑問**: ムニはどこから掛けている? なぜレニィと同じ青い髪(声の記述と夢の証言)?

## 第二章「ともしび編」(Day4〜6) 事件
- **事件**: **ジンパチ**が初着信。「親友カナタが消えた。警察は家出だと言う」。相談中、カナタの部屋から発見された録音に謎の低周波音。第2の失踪発生(ニュース幕間)。**ゲル**が身元を伏せて探りの電話を掛けてくる。
- **張る伏線**: ①ジンパチの嘘「俺は心配してねえ」 ②ゲル「十年前の火事を覚えているか」 ③失踪者は全員「灯守園」出身か関係者 ④低周波音はムニ回線のノイズと同一波形(録音照合で発見可能)
- **回収**: 一章の無言留守電→失踪者たちが消える直前に掛けた未遂のSOSだった
- **終了時の疑問**: 失踪と十年前の火災の関係は? ゲルは何者?

## 第三章「かがみめ編」(Day6〜8) 謎と恐怖の頂点①
- **事件**: **ヒュウ**が着信。「私の右目に映るものの話を、笑わずに聞いていただけますか」。前髪の下の右目には「消えた人が立っている場所」が視える。ヒュウが失踪現場を視てしまい、何者かに追われる。章末、通話中にヒュウの声が遠ざかり回線断——**ヒュウ消失**。
- **張る伏線**: ①ヒュウ「幼い頃、白い部屋で青い夢を見せられた」 ②追跡者の靴音は跛行(灰堂の左足) ③ネオの声が一瞬混線する(「逃げろ、と伝えろ」)
- **回収**: ヒュウのナルシシズム=実験で「欠陥品」と呼ばれた自己否定の裏返し/失踪者の共通点=〈青い夢計画〉被験者
- **終了時の疑問**: ヒュウは死んだのか? 混線してきた男(ネオ)は敵か味方か?

## 第四章「よふかし編」(Day8〜10) 恐怖の頂点②→偽りの安心
- **事件**: **ネオ**から異常な着信(番号表示が文字化け)。「私の声が聞こえるか。貴様が"境界に届く耳"の持ち主だな」。二重音声・逆再生で意味が通る言葉などの怪異通話。中盤、ネオがヒュウを渡岸で保護していると判明(安堵)。同時に、ムニ回線の逆探知が成功し——**発信元は十年前の灯守園**(第1のどんでん返し)。
- **張る伏線**: ①ネオ「この裂け目は"人の手"で開けられた」 ②ムニ「あしたね、お祭りなんだよ」=十年前の8/13 ③ネオが主人公の声に妙な既視感を口にする
- **回収**: ムニの「ずっと夏」・雨音・3:33・存在しない局番=時間差通話/ネオの正体=異空間の魔法剣士(監視者)
- **終了時の疑問**: 十年前のムニを救えるのか? 裂け目を開けた「人の手」とは誰だ?

## 第五章「ほむら編」(Day10〜12) 安心→さらに大きな事件
- **事件**: ゲルが正体を明かす。「私は放火犯とされた男の娘だ。父は無実だと信じている」。証拠照合で灰堂の存在が浮上。真相に近づいた矢先——現在のレニィが失踪(灰堂の最重要標的=ムニの兄)。ジンパチが単身乗り込もうとし、ゲルは復讐に走ろうとする。電話だけで二人を止められるか。
- **張る伏線**: ①灰堂の目的は「十年前に取り逃した最後の被験者の回収」 ②室井の残した録音テープが相談室の棚から見つかる(十年前のムニのSOSの記録) ③テープ末尾の室井の独白「7人目の子は、どこへ消えたんだ」
- **回収**: ゲルの探りの真意/ジンパチの嘘(本当はカナタを助けられなかった自分を許せない)/剛三の冤罪の構図
- **終了時の疑問**: 8/14に何が起こる? 「7人目の子」とは誰?

## 終章「あさやけ編」(Day13〜14) 全収束
- **事件**: 8/14深夜、裂け目最大開放。3回線同時対応: ①現在=礼拝堂跡に囚われたレニィ+突入するジンパチとゲル ②異空間=ネオとヒュウ ③十年前=火災の夜のムニ。3:33、十年前と現在が一本の回線で繋がる。プレイヤーの言葉だけで、十年前のムニを火から逃がし、現在の全員を救い、裂け目を閉じる。
- **回収**: レニィの眠り(夢=ムニの残留思念との接触)/年表の空白行/室井の切電の贖罪(プレイヤーが「十年前に切られた電話」を今度は切らずに取り続けることで上書きされる)
- **TRUE最終の一撃**: すべてが終わった朝、ムニ(生きて15歳になった世界)から着信。「はじめまして。でも、なんだか懐かしい声だね」

## 全章共通の設計ルール
- 各章に「後から意味が反転する台詞」を最低3つ。
- 章末は必ず①強い引き(疑問) ②留守電1件(次章の予告を兼ねる)で締める。
- 幕間ニュースはプレイヤーの選択結果を反映し、周回時の差分を可視化する。

# 5. キャラクター完全設計

口調は指定仕様を厳守: レニィ(一人称「僕」/〜だよ・〜だね、稀に「〜だよぉ」/ジンパチ・ヒュウを呼び捨て)、ヒュウ(敬語/レニィ呼び捨て・「ジンパチくん」)、ジンパチ(一人称「俺」俺様熱血)、ゲル(一人称「私」/〜だな・〜だ ※「貴様」は絶対に使わない)、ネオ(一人称「私」二人称「貴様」/〜だ・〜だな)。

## レニィ(男子学生/青い髪・青い目)
- **秘密**: 十年前の火災の生き残りで、死んだ弟ムニの兄。記憶は封印されている。
- **弱さ**: 眠りに逃げる癖。夢の中だけ「誰か」と一緒にいられるから起きたくない。
- **恐怖**: 目が覚めたとき、大事な何かを忘れている気がすること。火と焦げた匂い。
- **願い**: 「夢の中の子に、ちゃんと名前で呼びかけたい」。
- **嘘**: 「僕、悩みなんてないよ? 眠いだけだよぉ」。
- **本音**: 自分の中に空洞があるのを知っていて、ずっと怖い。
- **隠していること**: 3:33に必ず目が覚めること。左手首の火傷跡。
- **最終的な成長**: 記憶と向き合い、「忘れることで守られていた自分」を許し、兄として弟の名を呼ぶ。
- **死亡ルート**: 五章で灰堂に攫われ、器として裂け目に呑まれる(信頼度不足で居場所の手掛かりを話してもらえなかった場合)。
- **救済ルート**: 通話でレニィの断片記憶を否定せず聞き切る→自力で礼拝堂跡から逃げ延びる。
- **TRUEルート**: 十年前のムニ生存により歴史改変。「弟とケンカばかりの、よく寝る兄」として朝の街を歩く。

## ヒュウ(男子学生/緑の髪・前髪で隠した赤い右目)
- **秘密**: 右目は〈青い夢計画〉の実験痕。境界の向こうと「消えた人の座標」が視える。
- **弱さ**: 「欠陥品」と呼ばれた記憶。美しく振る舞うのは自分を保つ鎧。
- **恐怖**: 右目を見た人に化け物と呼ばれること。鏡。
- **願い**: 「この目を、誰かを助けるために一度でいいから使いたいのです」。
- **嘘**: 「私は完璧ですから、悩みなどありませんが?」。
- **本音**: 誰よりも「気味悪がらずに話を聞いてくれる人」を待っていた。
- **隠していること**: 失踪者の位置を最初から視えていたのに、怖くて黙っていたこと。
- **最終的な成長**: 前髪を上げ、右目を「呪い」ではなく「灯」と呼び直す。
- **死亡ルート**: 三章で追跡者から逃げる際、プレイヤーが「電話を切って走れ」と指示すると孤立し消息不明→渡岸の深部で衰弱死。
- **救済ルート**: 「切らずに一緒にいます」を選び続ける→ネオの保護に間に合う。
- **TRUEルート**: ネオと共に裂け目を内側から閉じる要となり、生還。ジンパチに右目を見せて「美しいでしょう?」と笑う。

## ジンパチ(男子学生/茶髪ツンツン)
- **秘密**: 失踪前夜、カナタからの着信を「明日でいいや」と無視した。
- **弱さ**: 罪悪感を怒りに変換してしまう。単独行動癖。
- **恐怖**: 「お前のせいだ」と言われること。留守電の再生ボタン。
- **願い**: カナタに「わりい、電話出れなくて」とただ謝りたい。
- **嘘**: 「俺は別に心配なんかしてねえ。ムカついてるだけだ」。

## 9-3. 画面・UI演出/電話ノイズ
- 通話中は受話器越しの音場(ローパスフィルタ)。相手の精神状態で声の距離感が変化。

# 10. 感情演出カタログ

## 鳥肌(戦慄)演出
1. 一章の平和な通話を三章以降に再生すると、背後に最初から囁き声が入っていたことに気づける(データとして本当に最初から入れておく)。
2. ムニの「あしたお祭りだよ」の日付と、幕間新聞の「十年前の祭りの写真」の日付が一致する瞬間。
3. 逆探知の結果画面に表示される住所が「現存しない番地」で、地図上では黒い焼け跡。
4. 四章、ネオの声とプレイヤーの選択肢テキストが一瞬シンクロする(「私の言葉を貴様が先に言うな」)。
5. 五章、室井テープの再生中、テープの中の着信音と「今」の着信音が同時に鳴る。
6. 履歴画面の一番下、Day1より前に一件だけ残る「発信: 10年前」の記録(SECRET伏線)。
7. 保留音の主題歌がいつの間にか一番から二番(未公開歌詞)に進んでいる。
8. BAD ENDで受話器から聞こえる雑音を録音再生に掛けると、全キャラの「ありがとう」が重なってできた音だと分かる。
9. 終章、三回線同時通話で三人の呼吸がひとつのリズムに揃う音響演出。
10. 2周目の序章、レニィの第一声が「……あれ? 前にも話したこと、あるよね?」に差し変わる。

## 涙(号泣)演出
1. ムニ「でんわのおにいちゃん(おねえちゃん)のこえ、まくらもとにおいてねたい」→TRUEで15歳のムニが同じ言葉を照れながら言う。
2. ジンパチが留守電に残す、カナタへの言えなかった「わりい」。
3. ゲルが初めて父を「お父さん」と呼んで泣く場面(それまで一貫して「父」「あの人」)。
4. 室井の一言交信「切らないで、くれたんだな」。
5. ネオの別れ際の敬称「"あなた"の声は、境界のこちらまで届いていた」。
6. TRUE最終、着信を取るかどうかの最後の選択肢が「受ける」一択しか表示されない(取らない未来がもう存在しない)。

## 「続きが止まらない」引きの型
- 章末は必ず「通話が向こうから切れる」。
- 留守電1件を必ず残し、再生するかは翌章冒頭まで選べない。
- 幕間ニュースの最後に一行だけ次章の被害を予告(「市内でまた一人…」)。
